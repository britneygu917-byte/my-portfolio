# 指天椒病虫害 AI 识别系统

## 项目简介

针对大棚田间复杂工况的指天椒病虫害识别系统：摄像头实时采集 → YOLOv11 双模型推理 → 画面标注 → 离线语音播报。图像来自大棚实地采集并自行标注，训练输入 640×640。

## 技术栈

- 模型：YOLOv11（`ultralytics`），病害识别与成熟度识别两个模型并行推理
- 视觉：OpenCV、Pillow（检测框与标签绘制）
- 交互：Vosk 离线语音识别、Piper 中文语音合成

## 指标

| 指标 | 数值 |
|---|---|
| mAP@0.5 | 0.953 |
| F1-score | 0.91 |
| 训练输入尺寸 | 640×640 |

## 个人贡献

- 大棚实地采集与数据集标注（无现成数据可用）
- 针对田间工况设计多源数据集融合训练方案，配置数据增强并完成 YOLOv11 训练调优
- 实现摄像头实时推理、检测框标注与离线语音播报
- 与物联网工程师协作，把实时检测画面推送到其端侧，支撑联动决策

## 文件说明

- `智能指天椒检测.py` —— 主程序：双模型推理、画面标注、语音交互（约 700 行）
- `病虫害检测测试.py` —— 单图推理测试脚本，用于快速验证权重效果与批量导出结果

## 说明

脚本中的模型权重路径为本地绝对路径（`D:\指天椒检测\...`），运行前需替换为自己的权重文件位置；数据集与训练权重未随仓库上传。
